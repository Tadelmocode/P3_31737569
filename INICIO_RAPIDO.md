# 🚀 Inicio Rápido - Vinyl Store API

## ⚡ En 3 Pasos

### 1️⃣ Instalar Dependencias
```bash
npm install
```

### 2️⃣ Iniciar el Servidor
```bash
npm run dev
```

### 3️⃣ Abrir en el Navegador

## 🆘 Solución de Problemas

### El servidor no inicia
```bash
# Limpia node_modules
rm -rf node_modules
npm install
npm run dev
```

### Puerto 3000 en uso
```bash
# Cambia el puerto en src/server.ts
# O detén el proceso en el puerto 3000
```

### Estilos no se cargan
```bash
# Limpia caché del navegador
Ctrl + Shift + Delete (Chrome)
Cmd + Shift + Delete (Firefox)
```

### Animaciones lentas
```bash
# Verifica DevTools → Performance
# Desactiva extensiones del navegador
```
